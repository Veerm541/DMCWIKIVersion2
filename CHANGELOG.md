# Changelog

All notable changes to the Devil May Cry Wiki project will be documented here.

---

## [1.1.0] - 2026-09-22

### Added
- Supabase-powered fan comments.
- Cloudflare Turnstile bot protection.
- Supabase Edge Function for comment submissions.
- Akismet automatic spam filtering.
- Formspree email delivery for the Contact page.
- 30-question quiz database.
- Random selection of 15 quiz questions per session.
- Randomized quiz answer choices.

### Changed
- Reworked character lore to sound more natural and fan-written.
- Improved Characters page filters and dropdown styling.
- Improved mobile navigation behavior.
- Updated Contact page text and form behavior.
- Contact form now uses AJAX instead of fake frontend-only submission.

### Fixed
- Mobile hamburger menu transparency and spacing issues.
- Dropdown arrow positioning.
- Missing Lady ability icon.
- Missing Sparda ability icon.
- Broken Contact page HTML.
- Comment system previously limited to localStorage.

### Optimized
- Removed unused images and videos.
- Removed duplicate and unnecessary assets.
- Removed unused development files from deployment package.
- Compressed oversized image assets.
- Reduced project size from roughly 96 MB to around 8.8 MB zipped.
